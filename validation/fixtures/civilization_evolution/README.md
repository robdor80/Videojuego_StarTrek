# Civilization Evolution fixtures

These fixtures validate Block 1 only.

- `stable_growth_20y_v0.1.json`: twenty years of conservative aggregate demographic/capability evolution with no invented major event.
- `regime_change_v0.1.json`: an explicit constitutional crisis changes government while preserving civilization identity.
- `post_contact_divided_world_5y_v0.1.json`: two polity-scoped external relationships evolve independently; neither becomes planet-wide.
- `causal_extinction_v0.1.json`: extinction requires an already-authoritative causal event.

The fixtures are fictional game data, not Star Trek canon.
