# Procedural Conflict & War fixtures

Fictional validation data, not Star Trek canon.

- `doctrine_context_comparison_v0.1.json` proves that the same crisis can produce different policy responses from Klingon Imperial and Vulcan mainstream contexts without using species as an aggression variable.
- `weakened_klingon_restraint_v0.1.json` proves capability/exhaustion can override a more force-accepting doctrine.
- `strategic_operation_v0.1.json` resolves an off-screen strategic engagement using only pre-existing units and persistent damage.
- `war_lifecycle_v0.1.json` proves war → occupation/control → ceasefire → peace without automatic sovereignty transfer or history reset.
