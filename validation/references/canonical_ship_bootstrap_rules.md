# Validación de bootstrap de naves canónicas

1. Solo aplicar eventos de fuentes incluidas en el alcance.
2. Solo aplicar eventos anteriores/al punto de inicio.
3. No aplicar eventos posteriores después de crear el save.
4. Si la campaña previa ya divergió, el historial del save prevalece.
5. Una destrucción canónica anterior al comienzo impide estado activo salvo explicación de continuidad.
6. Un evento futuro de destrucción no se programa como destino inevitable.
7. Las excepciones individuales no se copian a la clase.
8. Las obras excluidas no alteran silenciosamente el World State.
