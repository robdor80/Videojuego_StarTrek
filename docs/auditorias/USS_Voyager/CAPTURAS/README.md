# Capturas: catálogo textual, sin publicación de imágenes

**Publicadas: ninguna. Solo en el MSI: 55.** No hay píxeles, miniaturas, texturas ni archivos de imagen en esta carpeta. El repositorio es público y no pudo confirmarse una licencia suficiente para publicar estas capturas; véase [publicación y límites](../README.md#publicacion-y-limites).

Las vistas proceden de Blender Workbench/Cycles o de láminas de imágenes reales ya existentes. Las capturas de corte omiten caras altas solo en sesiones temporales; no prueban ausencia de techo. Workbench muestra color difuso y no mapas de imagen. El índice local original permite abrir cada PNG desde el MSI.
