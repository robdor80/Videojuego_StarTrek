# STAR TREK — PROCEDURAL CONTENT DEPTH PLAN v0.1

**Status:** ACTIVE  
**Purpose:** populate the procedural architecture with source-grounded, gameplay-relevant Star Trek content without duplicating the CoreRPG engine.

## Rules

- Architecture lives in the 120-layer procedural master plan.
- This plan tracks **content depth**, not engine features.
- Unknown canon facts remain unknown.
- A species/culture/ship/world profile is not complete because a README exists; it must feed gameplay, validation and visual/NAP layers.
- Visual references define morphology/presentation grammar, not canonical-character templates.
- Species, culture, citizenship, organization, profession and personality remain independent.
