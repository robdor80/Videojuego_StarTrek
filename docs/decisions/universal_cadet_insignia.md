# Universal Cadet Insignia

Status: **APPROVED GAME DESIGN**

## Decision

All playable eras use a common cadet-class recognition system based on the 2360s Starfleet Academy cadet pips.

The pips are **silver**, clearly distinct from commissioned-officer gold pips.

## Mapping

| Academic year | Cadet class | Project insignia |
|---:|---|---|
| 1 | Cadete de 4.ª clase | 1 silver pip |
| 2 | Cadete de 3.ª clase | 2 silver pips |
| 3 | Cadete de 2.ª clase | 3 silver pips |
| 4 | Cadete de 1.ª clase | 4 silver pips |

## Canon vs game

The 2360s Academy used cadet class pips with the number of pips indicating class/year.

Other periods used different cadet insignia or no visible class pips.

The project intentionally standardises the silver-pip system across:
- Pike;
- Kirk;
- TNG/DS9/Voyager.

This is a `GAME_ADDITION` outside the 2360s-aligned presentation.

## 2370s note

On-screen 2370s cadet uniforms sometimes removed visible rank pips.

The game **retains silver cadet pips anyway** because Roberto explicitly chose universal TNG-style rank readability across eras.

## Separation

- silver pips = cadet academic class;
- gold/black pips = commissioned officer rank;
- framed gold pips = flag officer rank.

A cadet with four silver pips is **not** a Captain.
