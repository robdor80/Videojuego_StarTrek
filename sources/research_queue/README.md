# Research Queue

Living queue controlled by the project research workflow.

## Active sequence

### 0 — Documentary foundation
Status: **COMPLETE**

Canon policy, provenance policy, source registry and research workflow established.

### 1 — Chronology and era model
Status: **NEXT**

Goal:
- create a minimal master temporal backbone,
- define temporal anchors,
- define what an era profile contains,
- establish initial Pike, Kirk, TNG/DS9/Voyager and Picard campaign windows,
- explicitly account for alternate timelines/continuities rather than mixing them.

This pass is a structural chronology pass, not an attempt to document every event in Star Trek history.

### 3 — Starfleet Academy
Status: **QUEUED**

History, admissions, campus, curriculum, specializations, evaluations, simulations, training, graduation and first assignments, with era-aware differences.

### 4 — Career bridge
Status: **QUEUED**

Translate validated Starfleet/Academy lore into gameplay concepts for cadet → officer → assignments → transfers → promotions → command.

### 5 — Starfleet technology and ships
Status: **QUEUED**

Build the technical and vessel foundation after institutional and temporal rules are stable.

## Queue rule

Do not skip ahead because a topic is attractive. A later topic may be researched early only when it is a dependency of the active block.
