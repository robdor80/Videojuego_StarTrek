# Source Registry

This directory is the authoritative catalogue of external sources actually used by the project.

## Rules

- `source_registry.json` contains registered source families and foundational references.
- Individual episodes, films, novels and comic issues are added when they materially support researched content.
- Stable `source_id` values must not be recycled.
- A URL is not a canon level. Canon/authority classification follows `../canon_policy.md`.
- Discovery-only pages do not need permanent registry entries unless they become evidence.

## Initial source families

The baseline registry includes:
- official Star Trek Series & Movies catalogue,
- an official StarTrek.com discussion explicitly describing canon as on-screen continuity,
- the official Star Trek site as an official reference layer,
- Pocket Books / Simon & Schuster Star Trek publishing catalogue,
- IDW Publishing as a licensed Star Trek comics publisher,
- Memory Alpha as a specialist secondary research reference.

This registry will grow continuously as research proceeds.
