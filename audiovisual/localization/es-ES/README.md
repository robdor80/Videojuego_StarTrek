# Español (España) — es-ES

This is the **primary player-facing locale** of the Star Trek game.

Technical IDs may remain in English for code and data stability, but all normal UI and game-facing text must resolve through Spanish localization.

Canonical proper nouns that are conventionally retained in English may remain untranslated where appropriate, while ranks, positions, departments, actions and explanatory text are localized into natural Spanish from Spain.
