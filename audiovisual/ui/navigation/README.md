# UI — Navegación y Astrometría 360°

**Decisión del autor 18-11-2026: DISEÑO APROBADO, presentación UE5 NO IMPLEMENTADA.**

La familia UI de navigation ofrece tanto las pantallas de rumbo existentes como el nuevo **Sistema 11 — Astrometría 360°**.

- **Sala inmersiva:** proyección volumétrica en la Enterprise-D, recorrible/rotatoria, con cuatro escalas y holograma central.
- **Pantalla completa LCARS:** explorar, ciencia, rutas, capas e historial, sin exceso de submenús.
- **PADD:** misma vista autorizada en una presentación reducida y eficiente, no la escena entera duplicada.
- **Accesibilidad:** etiquetas, contraste, modo 2D/ortográfico, control por lista y cámara con movimiento reducido.
- **Controles:** teclado/ratón, mando, selección in-world y voz opcional, con fallback determinista si IA no está disponible.
- **Datos:** todos proceden de contratos de S11 con filtros HOST/Core; no se inventan rasgos astronómicos ni permisos.

Diseño principal: sistemas/gameplay/astrometrics/S11_ASTROMETRIA_360_DISENO_v1.md. Contrato de interacción: sistemas/gameplay/astrometrics/s11_interaction_contract_v0.1.json.

Se aplicará identidad visual Galaxy Refit A2 y LCARS cian/azul, pero **posición/arquitectura de la sala queda por concretar en la fase de interiores**.
