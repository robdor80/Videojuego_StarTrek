# Seguridad — Sistema 18: identidad, autenticación y accesos

**Decisión autoral DEC-0024, 18-11-2026.** Esta carpeta general de Seguridad no necesita otra base de identidad: el sistema especializado compartido está en [Sistema 18](../access_control/README.md).

S18 resuelve actor verificado, autorización para entrar en camarotes y áreas restringidas, invitaciones, revocaciones y excepciones registradas. Los procedimientos de Seguridad específicos de la Flota (incidentes, cuarentena y órdenes) siguen en sus autoridades, sin que una IA invente credenciales.

**Sistema 12** únicamente detecta la interacción y ejecuta apertura/cierre de hojas y transiciones, consultando S18 para recursos privados/restringidos. No confundir proximidad/identidad con permiso.

Estado: número/alcance aprobados; integración en Core/HOST/UE5 pendiente.
