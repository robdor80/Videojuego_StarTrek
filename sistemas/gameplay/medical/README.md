# Medicina a bordo

## Bucle jugable

```text
paciente
  ↓
triaje
  ↓
exploración / diagnóstico
  ↓
tratamiento
  ↓
respuesta
  ↓
seguimiento / aptitud para servicio
```

## Estado médico

El sistema distingue:
- lesión/enfermedad real;
- síntomas observables;
- pruebas disponibles;
- diagnóstico conocido;
- tratamiento;
- pronóstico.

Un médico no conoce automáticamente la causa real.

## Crisis

Si Enfermería supera capacidad, una nave grande puede habilitar zonas auxiliares para:
- triaje;
- hospitalización;
- aislamiento;
- morgue.

La capacidad depende de clase, instalaciones, personal y suministros.

## Aptitud para el servicio

El resultado médico puede actualizar:
- apto;
- apto con limitaciones;
- no apto.

Esto conecta con la autoridad médica ya definida para relevar temporalmente de servicio.

## IA

La IA puede:
- dialogar con paciente;
- explicar diagnóstico conocido;
- actuar como NPC médico;
- generar bedside manner.

El Core decide:
- lesión;
- signos;
- pruebas;
- tratamiento válido;
- evolución;
- aptitud.
