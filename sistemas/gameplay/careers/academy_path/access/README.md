# Acceso a Starfleet Academy

Contiene el temario oficial de acceso, el manual del candidato y el modelo de evaluación.

## Regla de profundidad

```text
ACCESO
→ reconocimiento y cultura general

ACADEMIA
→ comprensión profesional, procedimiento, práctica y evaluación
```

## Artefactos

- `access_curriculum_v1_0.json`
- `candidate_manual_v1_0.md`
- `admission_assessment_model_v1_0.json`

El acceso produce candidatura, evidencias, áreas de refuerzo, decisión de admisión e historial de intentos. No concede cualificaciones profesionales.
