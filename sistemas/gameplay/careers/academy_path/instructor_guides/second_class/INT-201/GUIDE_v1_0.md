# Guía de instructor — INT-201 Operaciones integradas de nave II

**v1.0**

## Propósito

Entender cómo la especialidad propia consume, modifica y entrega información o recursos al resto de la nave.

## Regla docente

En 2.ª clase la ayuda debe retirarse de forma planificada. El instructor prepara un entorno seguro y autoritativo, permite que el cadete tome decisiones y usa el debrief para separar conocimiento, ejecución y juicio.

**Variación recomendada:** repetir el caso cambiando una restricción relevante para comprobar transferencia, no memorización del guion.
