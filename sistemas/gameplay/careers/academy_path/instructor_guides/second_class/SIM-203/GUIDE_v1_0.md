# Guía de instructor — SIM-203 Simulación operacional compleja II

**v1.0**

## Propósito

Probar la rama dentro de una misión que combina carga, degradación, personas y objetivos en conflicto.

## Regla docente

En 2.ª clase la ayuda debe retirarse de forma planificada. El instructor prepara un entorno seguro y autoritativo, permite que el cadete tome decisiones y usa el debrief para separar conocimiento, ejecución y juicio.

### SIM-203-U01 — Briefing incompleto

**Contenido:** datos conocidos; incertidumbre; roles; restricciones.

**Práctica mínima:** Preparar misión.

**Evidencia objetivo:** Evaluación.

**Variación recomendada:** repetir el caso cambiando una restricción relevante para comprobar transferencia, no memorización del guion.

Definir la brecha concreta y repetir solo la parte necesaria. Una mala ejecución no debe convertirse automáticamente en fallo anual.
