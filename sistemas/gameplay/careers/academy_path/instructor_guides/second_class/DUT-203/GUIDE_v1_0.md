# Guía de instructor — DUT-203 Servicio supervisado de especialidad

**v1.0**

## Propósito

Ocupar temporalmente un puesto de la rama bajo supervisión y generar evidencia profesional real.

## Regla docente

En 2.ª clase la ayuda debe retirarse de forma planificada. El instructor prepara un entorno seguro y autoritativo, permite que el cadete tome decisiones y usa el debrief para separar conocimiento, ejecución y juicio.

### DUT-203-U01 — Asignación y briefing

**Contenido:** puesto; supervisor; órdenes; límites.

**Práctica mínima:** Incorporación a turno.

**Evidencia objetivo:** Evaluación de preparación.

**Variación recomendada:** repetir el caso cambiando una restricción relevante para comprobar transferencia, no memorización del guion.
