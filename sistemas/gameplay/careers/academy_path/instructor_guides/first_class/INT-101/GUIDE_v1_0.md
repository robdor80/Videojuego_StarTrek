# Guía de instructor — INT-101 Operaciones integradas de nave III

**v1.0**

## Propósito

Pensar en la nave como sistema completo y anticipar efectos cruzados de decisiones profesionales.

## Doctrina docente

El instructor de 1.ª clase actúa cada vez más como supervisor profesional. No debe fabricar una crisis para que todas las guardias sean emocionantes: la rutina, la continuidad y la disciplina también generan evidencia válida.
