# Destinos operativos

## Incorporación

Un destino crea:
- unidad;
- puesto;
- superior directo;
- cadena de mando;
- fecha de incorporación;
- horario/guardia inicial;
- deberes;
- acceso y autorizaciones.

## Primer día

La incorporación puede jugarse:
- presentación al superior;
- orientación;
- asignación de camarote/puesto;
- primera guardia;
- encuentro con compañeros;
- primeras tareas.

## Vacantes

Las vacantes son estado del mundo.

No se inventa una plaza en una nave famosa solo para acomodar al jugador.

## Fin de destino

Un destino puede terminar por:
- traslado;
- ascenso;
- cambio de puesto;
- disciplina;
- petición propia;
- reorganización;
- pérdida/destrucción de unidad;
- necesidades de Starfleet;
- retiro/separación.
