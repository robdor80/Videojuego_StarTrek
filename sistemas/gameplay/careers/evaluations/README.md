# Evaluaciones de servicio

## Objetivo

El servicio activo produce evaluaciones periódicas y evaluaciones especiales.

No existe una única "barra de experiencia".

## Qué se evalúa

Según puesto:
- competencia profesional;
- cumplimiento de órdenes;
- iniciativa;
- liderazgo;
- trabajo en equipo;
- juicio;
- fiabilidad;
- conducta;
- adaptación;
- preparación para responsabilidades mayores.

## Autoridad

El superior correspondiente puede aportar evaluación y comentarios.

La IA puede redactar el comentario del superior.

El resultado estructurado debe salir de:
- hechos registrados;
- métricas del puesto;
- reglas;
- estado del mundo.

## Consecuencias

Una evaluación puede influir en:
- permanencia en puesto;
- tutoría;
- cualificaciones;
- recomendación;
- traslado;
- ascenso;
- candidatura a mando.
