# Selección de clase para una nave

## Generación de una unidad Starfleet

El sistema filtra:

1. fecha;
2. operador;
3. clase disponible;
4. rol requerido;
5. configuración/refit válido;
6. necesidades de campaña;
7. disponibilidad de recursos si el sistema la modela.

## Diseños veteranos

Una clase antigua no desaparece automáticamente al aparecer una nueva.

Ejemplo:

```text
2374
Galaxy disponible
Intrepid disponible
Defiant disponible
Excelsior todavía puede estar en servicio
Miranda todavía puede estar en servicio
```

Esto es importante para que Starfleet parezca una flota real y no un escaparate donde todas las naves son del modelo más nuevo.

## Selección por prestigio

No usar:

```text
jugador importante → clase más potente
```

El destino depende de la vacante y necesidades del servicio.

Un Alférez puede acabar en:
- una gran nave exploradora;
- una vieja Miranda;
- una pequeña nave científica;
- una estación;
- una base.

Todas deben poder generar juego interesante.
