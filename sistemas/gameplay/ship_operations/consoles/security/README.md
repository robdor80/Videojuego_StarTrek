# Seguridad

Familia funcional `security`. Pendiente de definición detallada.

## Dependencia de S18 (18-11-2026)

S18 es el sistema transversal para resolver **identidad auténtica de jugador y NPC, permisos, visitas, revocaciones y excepciones**. La consola de Seguridad aplica procedimientos de su dominio, no mantiene una segunda identidad. La autorización no depende de que la IA diga «abrir».

Ver `sistemas/gameplay/access_control/README.md`. Todavía sin integración UE5.
