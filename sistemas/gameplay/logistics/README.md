# Logística operativa

Star Trek puede aliviar muchas necesidades materiales mediante tecnologías avanzadas, pero una nave sigue teniendo límites operativos.

El juego modela logística como varias dimensiones:

```text
propulsión / reactantes
energía
munición y consumibles
probes
repuestos
componentes especializados
medicina
equipos de emergencia
carga
lanzaderas
mantenimiento
fatiga de tripulación
```

No existe una única barra universal de «combustible».

## Consecuencia jugable

Antes de aceptar una misión, Core puede determinar:

```text
VIABLE
VIABLE CON APOYO PLANIFICADO
CONDICIONAL
NO VIABLE
DESCONOCIDO
```

Una misión puede requerir:
- parada de reabastecimiento;
- reparación previa;
- apoyo de otra nave;
- reducción de carga;
- cambio de ruta;
- aceptación explícita de riesgo.

La IA informa y representa a oficiales/logística, pero el estado de recursos y servicios pertenece al Core.
