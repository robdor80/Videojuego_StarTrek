# Canon vs Campaign

## Runtime rule

At campaign creation:

1. Select era.
2. Select campaign date / starting context.
3. Load canon-valid world state up to that date.
4. Create the player's campaign.
5. From that moment onward, live save-state history outranks future television canon.

## Never do this

- Force an episode because "it is supposed to happen".
- Force a known character death because canon says it occurs later.
- Force Voyager to return to Earth on schedule.
- Force Enterprise-D to follow its canonical future.
- Force wars, promotions, assignments or discoveries merely because they happened after campaign start on screen.

## Allowed use of future canon

Future canon can be used only as:
- optional inspiration,
- probability/context input,
- reusable world knowledge,
- event seeds that still require valid in-game causes.

## Principle

**The game begins in Star Trek canon; it does not remain chained to Star Trek scripts.**
