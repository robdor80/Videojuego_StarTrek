# Chronology

This directory defines the temporal model used by the Star Trek universe pack.

## Core rule

**Chronology defines what exists at campaign start; it does not force the campaign to replay television or film plots.**

The game uses two different concepts:

1. **Reference history** — canon facts established up to the campaign start date.
2. **Campaign history** — what actually happens after the player begins.

Future canon is reference material, not destiny.

## Playable era (author decision 2026-10-23)

- `tng_ds9_voyager` — **the only selectable campaign era**, 2364–2378 reference window; precise campaign start date undecided.
- `pike` and `kirk` — **retained historical profiles**, not playable. Their chronology and past sources remain available.

## Temporal validity

Every chronology-sensitive record should eventually be able to answer when it becomes valid, when it stops being valid, whether the date is exact or approximate, what continuity it belongs to, and which source supports it.

Broad era membership is never enough. A campaign date determines the canonical starting state. Once play begins, the save's live world state becomes authoritative.

See `proyecto/docs/decisions/playable_eras.md`, `proyecto/docs/decisions/campaign_continuity.md` and `sistemas/universe/global_rules/canon_vs_campaign.md`.
