# Experiencia in-game - Manual de Operador de Sensores

Estado: **SPEC v0.1**

## Objetivo

El manual debe existir dentro de la Academia como material de estudio tipo PADD/LCARS y, más adelante, como referencia desde Ordenador/Base de datos de una nave. No debe sentirse como una wiki externa.

## Superficies

- **Academia / PADD de estudio:** lectura guiada, índice, marcadores, ejercicios y acceso a prácticas.
- **Nave / Ordenador:** consulta rápida durante servicio y búsqueda por función o término.

## Navegación

```text
PADD - SENSORES
|-- Continuar estudio
|-- Índice
|-- Procedimientos
|-- Ejercicios
|-- Referencia rápida
|-- Marcadores
`-- Buscar
```

## Reglas UX

- Usa el contenido canónico del manual v0.1.
- Cada sección puede enlazar con la operación real correspondiente en modo práctica.
- La presentación visual cambia con la era/nave; la operación funcional no.
- Permite marcadores, búsqueda y enlaces entre conceptos.
- En Academia, un instructor puede asignar secciones y ejercicios.
- Los ejercicios E-01 a E-06 lanzan escenarios de práctica contra el backend real.
- Leer el manual no concede bonificaciones ocultas.
- En una nave, abrir la ayuda no tiene por qué pausar el mundo; depende del modo de juego.
- Estética PADD/LCARS con acento de Ciencias y emblema de Flota/Academia.
- El PDF externo y el manual in-game comparten la misma base funcional y deben versionarse juntos.
