# Experimentos locales

Los experimentos nuevos se realizan en UE5, Blender o PruebasTecnicas dentro de esta carpeta y usan copias de recursos. Todo su contenido queda fuera de Git salvo este documento. No se han recreado laboratorios eliminados.

Un laboratorio solo podrá declararse eliminable después de integrar resultados, código y dependencias en el juego, verificar allí el funcionamiento y comprobar que no queda ninguna dependencia hacia el laboratorio. Esta tarea no elimina ningún laboratorio. La decisión de borrarlo corresponde al usuario.

Las auditorías y pruebas antiguas con referencias pendientes permanecen en sus rutas existentes, registradas en `../archivo_historico/README.md`.
