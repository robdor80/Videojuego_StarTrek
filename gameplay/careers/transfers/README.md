# Traslados

## Formas

Un traslado puede ser:
- solicitado;
- ordenado;
- temporal;
- por necesidad operativa;
- ligado a ascenso;
- ligado a disciplina;
- ligado a formación.

## Petición del jugador

El jugador puede solicitar un destino.

El sistema evalúa:
- vacante;
- cualificación;
- necesidades;
- expediente;
- cadena de mando;
- fecha y distancia;
- estado de campaña.

La petición puede:
- aprobarse;
- quedar pendiente;
- denegarse;
- ofrecer una alternativa.

## Consecuencia

Un traslado cambia destino y quizá puesto, pero no necesariamente rango.
