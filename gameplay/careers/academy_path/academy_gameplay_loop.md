# Bucle jugable de la Academia

## Unidad de juego

La unidad básica no será "leer una entrada de lore", sino **vivir un bloque de tiempo como cadete**.

Ejemplo:

```text
07:00 — alojamiento de cadetes
08:00 — clase
10:00 — práctica
12:00 — comida / interacción
14:00 — simulación
17:00 — tiempo libre
20:00 — estudio / actividad / evento
23:00 — descanso
```

Los horarios exactos son contenido configurable. El ejemplo muestra el tipo de estructura.

## Acciones posibles

Según hora, lugar y estado:

- asistir a clase;
- estudiar;
- entrenar;
- practicar en simulador;
- hablar con un NPC;
- acudir a tutoría;
- aceptar/rechazar una actividad;
- explorar una localización disponible;
- descansar;
- socializar;
- mantener relaciones personales;
- incumplir una obligación;
- responder a un evento emergente.

## Resultado

Las acciones pueden aportar evidencia o modificar:

- conocimientos/competencias;
- evaluaciones;
- cualificaciones;
- hábitos y recuperación;
- relaciones;
- reputación profesional/social contextual;
- disciplina;
- oportunidades;
- eventos futuros.

No se requiere presentar estos cambios como barras arcade.

## Aprendizaje

Cada unidad académica puede seguir:

```text
THEORY
→ CLASS
→ PRACTICE
→ EVALUATION
```

La práctica utiliza sistemas reales siempre que existan.

## IA

La IA puede:

- interpretar diálogos;
- enseñar;
- reformular explicaciones;
- generar variaciones compatibles de ejercicios;
- dirigir expresión de NPCs dentro de su conocimiento;
- explicar una evaluación basada en evidencia.

La IA **no** decide por sí sola:

- notas;
- acceso;
- horarios;
- sanciones;
- progresión;
- cualificaciones;
- graduación.

Esos cambios pasan por reglas/estado autoritativo.
