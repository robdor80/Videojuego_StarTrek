# Resolución de asignaturas

## Estado de curso

Cada matrícula puede estar en:

```text
planned
enrolled
in_progress
completed
remediation
failed
withdrawn
```

## Actividades

Un curso puede generar:
- clase teórica,
- práctica,
- tutoría,
- trabajo individual,
- trabajo en equipo,
- examen escrito/oral representado narrativamente,
- simulación,
- evaluación práctica.

## Resultado

El sistema evalúa:
- competencia del personaje,
- preparación,
- asistencia,
- fatiga/estrés,
- decisiones,
- dificultad,
- conducta cuando sea relevante.

## Usuario vs personaje

El usuario decide **cómo actuar**.

El personaje determina **qué sabe hacer**.

No se penaliza al usuario por no conocer ciencia ficticia de Star Trek.

## Recuperación

Un mal resultado puede abrir:
- tutoría,
- repetición,
- práctica adicional,
- recuperación,
- cambio de asignatura optativa,
- retraso académico.

La campaña debe intentar crear consecuencias antes que callejones sin salida.
