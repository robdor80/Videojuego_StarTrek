# FLD-302 — Formación de campo I

**Material de estudio v1.0 — edición desarrollada**  
**Cadete de 3.ª clase · Trimestre 2**

## Finalidad

Integrar procedimientos, equipo y criterio fuera del entorno controlado de aula o puente. FLD-302 enseña preparación de misión, movimiento, protección ambiental, comunicaciones, respuesta a incidentes y cierre de una salida.

La regla central es:

> **En campo, el plan sirve para empezar; la disciplina sirve para adaptarse cuando el plan deja de encajar.**

---

# FLD-302-U01 — Preparación de misión

## 1. Briefing

Antes de salir, el equipo debe conocer:
- objetivo;
- área;
- información disponible;
- restricciones;
- autoridad;
- duración prevista;
- apoyo;
- criterios de abort.

## 2. Roles

Cada miembro debe saber:
- función;
- responsable directo;
- equipo;
- tareas;
- límites.

## 3. Objetivos

**El objetivo debe ser observable.**

Ejemplo:
> “Cartografiar la zona y recoger tres muestras autorizadas.”

Es mejor que:
> “Investigar un poco.”

## 4. Equipo

El equipo se selecciona según:
- misión;
- entorno;
- rol;
- duración;
- riesgo;
- apoyo disponible.

## 5. Abort criteria

Antes de salir conviene definir qué condiciones obligan a:
- detener;
- volver;
- pedir extracción;
- cambiar objetivo.

Eso evita decidir bajo presión sin marco.

### Práctica

Preparar una salida de entrenamiento con roles, equipo y dos criterios de abort.

### Autoevaluación

1. ¿Qué debe contener briefing?
2. ¿Qué debe conocer cada rol?
3. ¿Por qué un objetivo debe ser observable?
4. ¿De qué depende el equipo?
5. ¿Para qué sirven criterios de abort?

# FLD-302-U02 — Movimiento y orientación

## 1. Navegar en campo

El equipo puede apoyarse en:
- mapa;
- sensores portátiles;
- referencias;
- coordenadas;
- comunicaciones.

## 2. Posición

Cada grupo debe mantener una idea razonable de:
- posición actual;
- dirección;
- ruta recorrida;
- destino;
- punto de retorno.

## 3. Cohesión

La velocidad del grupo debe permitir:
- mantener contacto;
- compartir información;
- asistir;
- reaccionar.

**Separarse sin plan aumenta incertidumbre.**

## 4. Puntos de reunión

Un punto de reunión ofrece referencia si:
- se pierde contacto;
- el grupo se divide;
- cambia la ruta.

Debe ser conocido antes de necesitarlo.

## 5. Sensores portátiles

Ayudan a observar y orientarse, pero:
- pueden fallar;
- sufrir interferencia;
- tener alcance limitado.

La orientación no debe depender de una sola fuente si existen alternativas.

### Práctica

Recorrido de campo con un tramo donde la lectura portátil se degrada.

### Autoevaluación

1. ¿Qué herramientas apoyan orientación?
2. ¿Qué información de posición debe conservarse?
3. ¿Por qué la cohesión importa?
4. ¿Para qué sirve un punto de reunión?
5. ¿Por qué no depender de una sola fuente?

# FLD-302-U03 — Ambiente y protección

## 1. El entorno es parte de la misión

Antes de operar se revisan:
- atmósfera;
- temperatura;
- presión;
- radiación contextual;
- terreno;
- agentes conocidos;
- duración de exposición.

## 2. Protección

Puede incluir:
- ropa;
- traje;
- respiración asistida;
- protección térmica;
- aislamiento;
- dosimetría u otro equipo contextual.

## 3. Aptitud

**Un entorno compatible con una especie puede no serlo con otra.**

La planificación debe utilizar perfiles reales de la tripulación.

## 4. Duración

Un nivel tolerable durante minutos puede no serlo durante horas.

Por eso importa:
- exposición;
- consumo;
- autonomía del equipo.

## 5. Cambio de condiciones

Si el entorno cambia:
- se reevalúa;
- se informa;
- se adapta equipo;
- se aplica criterio de abort si procede.

### Práctica

Seleccionar protección adecuada para tres entornos de entrenamiento.

### Autoevaluación

1. ¿Qué factores ambientales se revisan?
2. ¿Qué tipos de protección pueden existir?
3. ¿Por qué la especie importa?
4. ¿Por qué duración modifica riesgo?
5. ¿Qué haces si cambian condiciones?

# FLD-302-U04 — Comunicaciones de campo

## 1. Plan previo

Antes de salir se define:
- canal;
- identificadores;
- frecuencia de check-in;
- canal alternativo;
- procedimiento de pérdida de contacto.

## 2. Check-in

Un check-in confirma:
- posición aproximada;
- estado del equipo;
- progreso;
- incidencias.

**No necesita ser un informe largo.**

## 3. Pérdida de contacto

No debe improvisarse desde cero.

El equipo aplica:
- tiempo de espera previsto;
- canal alternativo;
- punto de reunión;
- intento de relay;
- escalado.

## 4. Mensaje de campo

Un informe útil prioriza:
- quién;
- dónde;
- qué ocurre;
- qué necesita.

## 5. Registro

Las comunicaciones relevantes pueden conservarse como parte de la misión.

### Práctica

Mantener comunicaciones durante un recorrido y resolver una pérdida temporal de enlace.

### Autoevaluación

1. ¿Qué debe definir el plan de comunicaciones?
2. ¿Qué contiene un check-in?
3. ¿Qué se hace ante pérdida de contacto?
4. ¿Qué prioriza un mensaje de campo?
5. ¿Por qué registrar comunicaciones relevantes?

# FLD-302-U05 — Incidente de campo

## 1. La misión puede cambiar

Un incidente puede obligar a:
- modificar objetivo;
- detener;
- asistir;
- retirarse;
- pedir apoyo.

## 2. Herido

Un herido afecta:
- movilidad;
- ritmo;
- recursos;
- comunicaciones;
- prioridad.

**La misión original puede dejar de ser prioritaria.**

## 3. Riesgo

El equipo debe distinguir:
- riesgo conocido;
- riesgo estimado;
- incertidumbre.

No se inventa certeza.

## 4. Cambio de misión

Un cambio debe ser:
- autorizado cuando corresponda;
- comunicado;
- entendido por el grupo.

## 5. Retirada

Retirarse es correcto cuando:
- objetivo deja de compensar riesgo;
- se cumple criterio de abort;
- se pierde capacidad esencial;
- una persona necesita extracción;
- autoridad lo ordena.

### Práctica

Resolver un incidente controlado con un herido y un riesgo ambiental nuevo.

### Autoevaluación

1. ¿Qué puede cambiar un incidente?
2. ¿Cómo afecta un herido?
3. Diferencia riesgo conocido e incertidumbre.
4. ¿Qué necesita un cambio de misión?
5. ¿Cuándo retirarse es profesionalmente correcto?

# FLD-302-U06 — Extracción y debrief

## 1. Recuento

Antes de cerrar una salida:
- confirmar personas;
- confirmar equipo crítico;
- confirmar material o muestras;
- informar pérdidas.

## 2. Extracción

La extracción requiere:
- punto;
- hora o ventana;
- comunicaciones;
- acceso seguro;
- prioridad.

## 3. Handoff

Si hay:
- heridos;
- muestras;
- datos;
- equipo con anomalías,

**deben entregarse al responsable adecuado.**

## 4. Registro

La misión debe conservar:
- hechos;
- tiempos;
- decisiones;
- cambios;
- incidencias;
- resultado.

## 5. Debrief

El debrief pregunta:
- qué se sabía;
- qué ocurrió;
- qué se decidió;
- qué salió bien;
- qué debe cambiar.

No busca inventar culpa retrospectiva.

### Práctica

Cerrar misión, entregar materiales y realizar debrief.

### Autoevaluación

1. ¿Qué debe incluir recuento?
2. ¿Qué necesita una extracción?
3. ¿Qué elementos pueden requerir handoff?
4. ¿Qué debe conservar el registro?
5. ¿Qué busca el debrief?

# Evaluación del curso

FLD-302 evalúa preparación, cohesión, adaptación, comunicaciones, juicio y cierre profesional.

# Tratamiento por era

El activo de entrenamiento puede ser:
- nave;
- lanzadera;
- instalación;
- simulador;
- unidad activa.

No se garantiza una nave famosa: debe ser compatible con era, fecha, disponibilidad y World State.
