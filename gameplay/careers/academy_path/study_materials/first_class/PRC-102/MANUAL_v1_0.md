# PRC-102 — Prácticum / crucero de formación

**Material de estudio v2.0 — Cadete de 1.ª clase**

## Finalidad

Exponer al cadete a servicio real o casi real durante un periodo significativo en una unidad o instalación apropiada.

## Enfoque de último año

El cadete trabaja ya con un estándar próximo al servicio: **autonomía dentro de autoridad, continuidad, comunicación profesional y responsabilidad por las decisiones**.

## PRC-102-U01 — Asignación de prácticum

### Objetivo operativo

Al completar esta unidad, el cadete debe integrar los elementos de **Asignación de prácticum** sin perder seguridad, prioridades ni continuidad.

### Contenidos

- **unidad**: nave, estación o instalación donde se presta servicio, con misión, organización y capacidades propias.
- **supervisor**: responsable que observa, limita y valida el trabajo del cadete durante una actividad formativa.
- **puesto**: función concreta con responsabilidades, autoridad, interfaces y requisitos definidos.
- **alcance**: frontera de tareas y decisiones autorizadas durante una actividad o asignación.
- **reglas**: normas y restricciones aplicables que continúan vigentes incluso bajo presión.

### Aplicación profesional

Antes de actuar se distingue lo confirmado de lo incierto, se comprueban límites y responsables, se ejecuta la opción proporcionada y se conserva lo necesario para seguimiento, relevo y debrief.

### Práctica

Recibir órdenes de incorporación.

### Criterio de servicio

El prácticum observa servicio realista: no necesita una crisis artificial para producir evidencia sobre disciplina, constancia, juicio y convivencia profesional.

### Evaluación

Validación. Se valora el proceso con la información disponible entonces, no solo el resultado conocido después.

### Repaso interactivo

El repaso dinámico utiliza únicamente conceptos enseñados en esta unidad.
