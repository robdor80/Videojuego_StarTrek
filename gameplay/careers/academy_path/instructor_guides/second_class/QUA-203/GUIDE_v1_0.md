# Guía de instructor — QUA-203 Cualificación intermedia

**v1.0**

## Propósito

Determinar mediante evidencia si el cadete está preparado para entrar en 1.ª clase con trabajo profesional avanzado.

## Regla docente

En 2.ª clase la ayuda debe retirarse de forma planificada. El instructor prepara un entorno seguro y autoritativo, permite que el cadete tome decisiones y usa el debrief para separar conocimiento, ejecución y juicio.

### QUA-203-U01 — Revisión de evidencia

**Contenido:** cursos; prácticas; simulaciones; servicio; proyecto.

**Práctica mínima:** Compilar expediente.

**Evidencia objetivo:** Validación de integridad.

**Variación recomendada:** repetir el caso cambiando una restricción relevante para comprobar transferencia, no memorización del guion.
