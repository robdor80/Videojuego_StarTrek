# Guía de instructor — RSK-202 Operaciones degradadas y contingencias

**v1.0**

## Propósito

Trabajar de forma segura cuando sistemas, información o personal no están disponibles en condiciones normales.

## Regla docente

En 2.ª clase la ayuda debe retirarse de forma planificada. El instructor prepara un entorno seguro y autoritativo, permite que el cadete tome decisiones y usa el debrief para separar conocimiento, ejecución y juicio.

### RSK-202-U01 — Degradación y redundancia

**Contenido:** capacidad reducida; backup; aislamiento; margen.

**Práctica mínima:** Interpretar estado degradado.

**Evidencia objetivo:** Caso.

**Variación recomendada:** repetir el caso cambiando una restricción relevante para comprobar transferencia, no memorización del guion.
