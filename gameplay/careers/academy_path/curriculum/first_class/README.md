## Principio de graduación

La Academia no fabrica expertos.

> **Fabrica oficiales noveles preparados para entrar en servicio.**

La preparación para comisión se evalúa con evidencia acumulada de los cuatro años y no con un único examen final.

## Kobayashi Maru

Todos los cadetes participan, con puesto y responsabilidades coherentes con su rama y con la era de campaña.

No se evalúa «ganar» el escenario. Se observan juicio, responsabilidad, comunicación, ética, disciplina profesional, riesgo, uso de recursos y reacción ante incertidumbre.

## Primer destino

Las preferencias del jugador se cruzan con:
- especialidad;
- cualificaciones;
- expediente;
- recomendaciones;
- vacantes reales;
- necesidades de Starfleet;
- fecha y estado de campaña.

No existe elección garantizada de una nave concreta.

## Graduación

La graduación y comisión son jugables y cierran el expediente de Academia como registro histórico persistente.

El personaje sale de la Academia como **Alférez**, salvo reglas de campaña/ruta profesional explícitamente documentadas que indiquen otra cosa.
