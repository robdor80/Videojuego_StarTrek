# Ascensos jugables

## Pipeline

```text
SERVICIO
   ↓
EVALUACIONES
   ↓
ELEGIBILIDAD
   ↓
RECOMENDACIÓN / REVISIÓN
   ↓
DECISIÓN
   ↓
ASCENSO O APLAZAMIENTO
```

## Sin XP automático

La experiencia puede existir internamente, pero no produce el ascenso por sí sola.

## Factores

- tiempo y experiencia relevante;
- calidad de servicio;
- cualificaciones;
- mando ejercido;
- disciplina;
- recomendaciones;
- necesidades de Starfleet;
- disponibilidad de puestos;
- rango actual;
- estado de campaña.

## Ceremonia

Cuando un ascenso ocurre, puede representarse con:
- orden;
- diálogo del superior;
- cambio de pips;
- actualización de puesto;
- posible traslado.

## Camino hacia Capitán

Llegar a Capitán requiere más que acumular rangos:
- cualificación de mando;
- experiencia;
- puestos de responsabilidad;
- historial adecuado;
- oportunidad de mando.

No existe un contador secreto que garantice una nave.
