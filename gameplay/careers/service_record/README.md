# Expediente de servicio jugable

## Función

El expediente es la memoria profesional autoritativa del personaje.

No es un resumen escrito por la IA.

La IA puede redactar una versión narrativa, pero el registro estructurado es la verdad.

## Modelo

El expediente es **append-only**: se añaden eventos y no se reescribe el pasado para que encaje con una historia televisiva posterior.

Eventos típicos:
- admisión;
- matrícula;
- evaluación académica;
- graduación;
- comisión;
- destino;
- cambio de puesto;
- traslado;
- ascenso;
- descenso;
- condecoración;
- reprimenda;
- cualificación;
- mando provisional;
- herida/incapacidad relevante;
- separación del servicio;
- retiro.

## Uso

El sistema puede consultar el expediente para:
- promociones;
- asignaciones;
- diálogos;
- reputación;
- investigaciones;
- historial médico/profesional;
- recaps de carrera.
