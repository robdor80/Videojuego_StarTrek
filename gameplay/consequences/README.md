# Consecuencias operativas

Las consecuencias se derivan del World State y del registro autoritativo de acciones.

Una misión no se reduce a éxito/fracaso.

Puede producir simultáneamente:
- objetivos cumplidos;
- daños;
- bajas;
- cambios diplomáticos;
- nueva información;
- costes logísticos;
- reconocimientos;
- revisión disciplinaria;
- nuevas misiones;
- cambios en reputación o evaluación profesional.

## Carrera

No existe conversión automática:

```text
misión completada → XP → ascenso
```

En su lugar:

```text
acciones verificadas
→ evidencia de desempeño
→ evaluación
→ recomendaciones / historial
→ proceso de promoción cuando corresponda
```
