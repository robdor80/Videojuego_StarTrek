# Instalaciones, estaciones y apoyo operativo

Las estaciones y bases no son simples puntos de mapa. Son entidades operativas con capacidades y estado vivo.

## Separación principal

```text
INSTALACIÓN FÍSICA
      ≠
CAPACIDADES DE DISEÑO
      ≠
DISPONIBILIDAD ACTUAL
      ≠
ACCESO POLÍTICO
      ≠
COLA DE SERVICIO
```

Una base puede tener capacidad de reparación y, aun así:
- estar dañada;
- no tener piezas;
- estar saturada;
- encontrarse bajo bloqueo;
- negar acceso;
- reservar recursos para otra prioridad.

## Gameplay

Las instalaciones pueden ofrecer, según el caso:
- atraque;
- reabastecimiento;
- reparación;
- atención médica;
- transferencia de personal;
- carga;
- apoyo de lanzaderas;
- seguridad;
- mando;
- comunicaciones;
- diplomacia;
- comercio.

La existencia de una etiqueta no significa capacidad infinita.

## Persistencia

Daños, escasez, colas, cambios políticos y mejoras permanecen en campaña hasta que World State los modifique.
