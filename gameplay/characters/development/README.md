# Desarrollo de personaje

Sistema transversal para representar cómo las personas aprenden, mantienen, transfieren, mejoran y pierden parcialmente capacidades a través de su vida.

## Máxima

> **Vida → evidencia → capacidad → resolución contextual.**

No existe XP genérico ni reparto de puntos.

El sistema sirve por igual para:
- habilidades profesionales;
- conocimientos;
- actividad física;
- artes marciales;
- idiomas;
- artes;
- hobbies;
- oficios;
- competencias sociales o de liderazgo cuando exista evidencia apropiada.

## Separaciones

```text
CAPACIDAD
≠ CERTIFICACIÓN
≠ EXPERIENCIA
≠ ESTADO ACTUAL
```

Una persona puede conservar una certificación aunque esté desentrenada. Puede ser muy competente sin una certificación formal. Una lesión o fatiga puede reducir el rendimiento actual sin borrar la experiencia.

## Resolución

Cuando una capacidad importa, el motor combina evidencia relevante con estado y contexto. No usa una comparación simple de “skill 80 contra skill 70”.
