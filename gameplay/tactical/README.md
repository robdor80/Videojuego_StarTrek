# Táctica

## Bucle jugable

```text
DETECCIÓN
  ↓
identificación / amenaza
  ↓
decisión y reglas de enfrentamiento
  ↓
escudos / maniobra / armas
  ↓
impacto
  ↓
evaluación de daños
  ↓
nueva decisión
```

## Estado táctico

Táctica trabaja con **contactos conocidos**, no con la lista secreta de entidades del World State.

Un contacto puede ser:
- desconocido;
- probable;
- identificado;
- perdido;
- hostil;
- neutral;
- aliado.

## Armas

Una orden de fuego necesita:
- arma operativa;
- energía/munición;
- blanco;
- solución de tiro;
- autorización;
- arco/condiciones cuando proceda.

## Escudos

Táctica puede:
- elevar/bajar escudos;
- informar integridad;
- reforzar sectores si la configuración/reglas lo permiten;
- coordinar frecuencias/modulación cuando sea aplicable.

## Reglas de enfrentamiento

Ser hostil no significa disparar automáticamente.

El sistema conserva:
- postura;
- órdenes;
- Primera Directiva;
- autoridad;
- reglas de misión.

## No "HP sponge"

El combate debe producir daños de sistemas y consecuencias, no únicamente reducir una barra abstracta de vida.
