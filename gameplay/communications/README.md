# Comunicaciones

## Bucle jugable

```text
seleccionar destino/canal
      ↓
establecer enlace
      ↓
calidad / cifrado / traducción
      ↓
mensaje o conversación
      ↓
respuesta / retraso / pérdida
      ↓
registro
```

## Siglo XXIII

Comunicaciones puede existir como puesto dedicado del puente.

## Siglo XXIV

Muchas funciones se integran en Ops, Táctica y sistemas generales, aunque la función de comunicaciones sigue existiendo.

## Subespacio

Las comunicaciones interestelares usan redes/subespacio, pero el juego no asume conexión instantánea universal.

Puede haber:
- distancia;
- retraso;
- falta de relé;
- interferencia;
- bloqueo;
- cifrado;
- pérdida de señal.

## Hails

Abrir canal no garantiza que el otro acepte.

El receptor puede:
- responder;
- ignorar;
- bloquear;
- retrasar;
- engañar;
- enviar solo datos.

## Traducción

El traductor universal ayuda, pero no convierte toda comunicación desconocida en perfecta comprensión automática cuando el escenario establezca dificultad lingüística real.

## IA

La IA genera el diálogo del interlocutor basándose en:
- quién es;
- qué sabe;
- señal recibida;
- relación;
- objetivos;
- estado emocional.

No accede a información que no haya sido transmitida.
