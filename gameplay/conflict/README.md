# Strategic conflict

Star Trek-side rules for diplomatic crises, armed conflict, war, strategic operations, occupation and peace.

This layer is **strategic**:
- `gameplay/tactical/` resolves ship-level tactical state;
- `lore/conflicts/` stores historical/canon conflict definitions;
- `gameplay/conflict/` decides how live campaign conflicts emerge, escalate, operate and end.

Entry point: `conflict_war_index_v0.1.json`.
