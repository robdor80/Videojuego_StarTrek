# Ordenador / Base de datos

Familia funcional `computer`.

## Role

This console family exposes dedicated Computer/database functionality through a console surface.

It is **not** the Starship Computer service itself.

The ship-wide service lives at:

`gameplay/ship_operations/ship_computer/`

The same underlying Computer may also be accessed through voice, combadge, PADD, quarters, Engineering, Medical, bridge stations and other authorized interfaces.

## Principle

> **Console = one interface. Starship Computer = ship-wide service.**

Detailed query, access, action and AI-routing rules are defined by the ship-computer subsystem.
