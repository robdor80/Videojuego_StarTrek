# Ciencia y sensores

## Principio fundamental

```text
WORLD TRUTH
   ≠
SENSOR DATA
   ≠
CHARACTER KNOWLEDGE
   ≠
PLAYER REPORT
```

Esta separación es obligatoria.

## Bucle jugable

```text
pregunta científica
    ↓
seleccionar sensor / escaneo
    ↓
capturar datos
    ↓
calidad + interferencias + tiempo
    ↓
análisis
    ↓
hipótesis / identificación
    ↓
informe
```

## Tipos de acción

- escaneo pasivo;
- escaneo activo;
- escaneo de largo alcance;
- análisis detallado;
- lanzamiento de sonda;
- comparación con base de datos;
- seguimiento;
- análisis de anomalía;
- investigación de material/vida.

## Información parcial

Un escaneo puede devolver:
- dato confirmado;
- estimación;
- rango;
- hipótesis;
- desconocido;
- lectura contradictoria.

La IA debe hablar desde el resultado permitido, no desde la verdad secreta.

## Tiempo y riesgo

Más resolución puede requerir:
- acercarse;
- esperar;
- usar más energía;
- emitir una señal detectable;
- lanzar una sonda;
- exponer la nave.

Ciencia es una toma de decisiones, no un botón de «resolver misterio».
