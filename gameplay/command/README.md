# Misiones y órdenes operativas

Una misión no es un capítulo de guion. Es un conjunto de objetivos operativos emitidos por una autoridad válida y ejecutados sobre el World State vivo.

## Flujo

```text
situación del mundo
      ↓
necesidad operativa
      ↓
orden / misión
      ↓
briefing
      ↓
preparación
      ↓
navegación y ejecución
      ↓
objetivos cambian o se resuelven
      ↓
regreso / cierre
      ↓
debrief + consecuencias
```

## Reglas

- una misión puede salir bien, mal o a medias;
- un fracaso no implica terminar la campaña;
- los objetivos opcionales siguen siendo opcionales;
- el jugador puede resolver un problema de una forma no prevista si Core valida el resultado;
- una nueva orden puede modificar una misión en curso;
- el futuro canon no se ejecuta como guion;
- los personajes famosos no son necesarios para que una misión funcione.

## Mandato y táctica

Starfleet puede ordenar **qué debe conseguirse**.

El mando de la nave decide normalmente **cómo conseguirlo**, dentro de:
- autoridad;
- reglamentos;
- reglas de enfrentamiento;
- restricciones diplomáticas;
- capacidades reales de la nave.
