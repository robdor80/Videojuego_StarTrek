# Validación de capacidades de clase

1. Toda capacidad de clase debe ser válida para su fecha.
2. Una configuración datada puede añadir/quitar capacidades.
3. Una nave individual no puede usar una capacidad que su clase/configuración no tenga, salvo modificación registrada.
4. Una modificación de campaña debe producir un evento y quedar en el historial.
5. Tecnología experimental exige procedencia y restricciones.
6. Tecnología de una nave famosa no se generaliza automáticamente a toda la clase.
7. Una capacidad perdida por daño sigue definida en clase pero queda degradada/offline en el estado individual.
