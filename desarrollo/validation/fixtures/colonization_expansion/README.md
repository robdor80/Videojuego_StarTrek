# Colonization / Expansion fixtures

Fictional reference data, not Star Trek canon.

- `viable_colony_25y_v0.1.json`: founders and migrants are conserved while a supported colony becomes self-sustaining.
- `overlapping_claims_v0.1.json`: overlapping claims become disputed space without creating war.
- `abandoned_colony_v0.1.json`: route loss leads to evacuation; effective control ends while the historical claim remains distinct.
