# P2-B06 · Fixture sintético científico

`science_discovery_refit_v0.1.json` es un ejemplo **no canónico** de dos científicos y dos escáneres que corroboran una hipótesis, una junta la aprueba, ingeniería prepara un diseño, se reforma una única nave en astillero y sólo los ensayos aprobados activan la instalación. Un reconocimiento institucional acredita al equipo; un destinatario recibe el conocimiento sólo al comunicarse.

Los hechos `accepted`, permisos y presupuestos proceden **únicamente de este fixture declarado**. No constituyen firma ni validación de hechos/recursos por CoreRPG o HOST, ni demuestran que una nave del juego pueda utilizar ese diseño. Esta carpeta es una fixture de validación permanente, no un laboratorio temporal.

Prohibido convertir sus nombres, sucesos, hardware o recursos sintéticos en canon o configuración de producción por inferencia.
