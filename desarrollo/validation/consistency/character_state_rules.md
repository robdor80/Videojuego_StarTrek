# Character-state consistency rules

1. Identity, species, culture, citizenship, faction, rank, position and personality remain separate.
2. Canon biography initializes only pre-campaign history.
3. Generated NPCs are persistent after introduction.
4. World Truth and character knowledge are separate.
5. Character memory is not an authoritative copy of World Truth.
6. Relationships are directional and multidimensional.
7. Reputation is observer-specific, not global.
8. Dialogue may express hidden attitude but cannot leak unknown factual state.
9. In-character deception requires represented motive/intent and never changes World Truth.
10. AI cannot invent memories, authority, qualifications, relationships or private knowledge.
11. Species/culture may influence context but never replace personality.
12. Character state changes require authoritative events.
