# Facility reference-ingest validation rules

1. Bulk-downloaded files remain outside the game repository until reviewed.
2. Every imported reference set has provenance and a source-registry ID.
3. Downloader metadata does not determine canon authority.
4. Cygnus-X1 hosting alone does not make a blueprint official.
5. Original URLs, filenames and hashes are preserved in reference metadata.
6. Sheet ordering is normalized without modifying image content.
7. Printed technical claims and visible spatial geometry are treated as separate evidence types.
8. Individual facility data is not generalized to a class/design without support.
9. Missing geometry remains unknown rather than being invented.
10. Asset ingest and gameplay extraction should normally be separate commits.
11. Conflicting sheets are documented, not silently reconciled.
12. Only reviewed assets needed by the project are committed.
