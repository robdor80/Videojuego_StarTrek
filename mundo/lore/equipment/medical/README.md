# Equipamiento médico

Índice de familia `medical` del [catálogo único](../lore02_b_equipment_catalogue_v0.1.json): tricorder médico, sensor auxiliar, hipospray, cartuchos, botiquines y equipos de campo.

LORE-02 B especifica dispositivo, stock, autorización, fallos y observación. **LORE-02 C** tendrá la autoridad sobre hipótesis clínicas, diagnósticos, tratamientos, fisiología específica, privacidad y seguimiento. Ni UI ni IA curan ni diagnostican automáticamente.
