# Catálogo base de clases de la Flota Estelar

## Alcance

Este catálogo **no pretende ser exhaustivo**.

Contiene las primeras clases necesarias para que las tres eras jugables tengan:
- exploración;
- ciencia;
- apoyo;
- combate/seguridad;
- variedad de destinos;
- continuidad tecnológica entre siglos.

## Núcleo inicial

### Pike / TOS
- Constitution

### Kirk — películas

- Oberth

### TNG + DS9 + Voyager
- Galaxy
- Nebula
- Intrepid
- Defiant
- Sovereign — extensión tardía del siglo XXIV admitida explícitamente para presencia de clase
- Miranda, Excelsior y Oberth como diseños veteranos cuando sigan activos

## Regla de expansión

Las clases se añaden cuando:
- sean necesarias para una fecha;
- aparezcan en una misión/campaña;
- hagan falta para generar destinos;
- aporten un rol distinto.

No rellenaremos cientos de clases antes de necesitarlas.

## Regla de identidad

Una clase no es una nave.

`Galaxy` puede generar muchas naves.

`USS Enterprise-D` es una sola nave individual de esa clase.
