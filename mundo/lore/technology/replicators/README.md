# Síntesis de materia y replicadores

## Siglo XXIII

Las naves de Starfleet usan tecnologías de síntesis de alimentos y otros sistemas de producción a bordo.

Para el juego, se distingue de forma deliberada entre:

- `food_synthesizer` / sintetizador de alimentos;
- `full_replicator` / replicador molecular avanzado del siglo XXIV.

No se tratará una ranura de comida de TOS como si fuera automáticamente un replicador TNG.

## Siglo XXIV

Los replicadores son tecnología madura en las naves compatibles y pueden:
- producir alimentos;
- fabricar muchos objetos;
- reciclar materia según sistema/contexto.

El consumo energético y restricciones pertenecen a la nave y a sus reglas.

## Gameplay

El sistema de inventario puede consultar:
- si hay replicador/sintetizador;
- energía disponible;
- patrones autorizados;
- materia/reservas;
- restricciones de seguridad.

La IA no puede "replicar cualquier cosa" sin que el sistema lo permita.
