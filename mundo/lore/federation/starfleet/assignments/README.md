# Destinos y traslados

## Destino

Un destino es la nave, estación, instalación, unidad u organismo al que una persona está asignada.

El destino es independiente de:
- rango,
- departamento,
- puesto,
- turno,
- puesto de servicio.

## Traslado

Un traslado o reasignación puede:
- ser ordenado por Starfleet,
- ser solicitado por el propio oficial,
- acompañar un ascenso,
- acompañar un cambio de puesto,
- ser consecuencia disciplinaria,
- responder a necesidades operativas.

## Regla del juego

Un personaje puede cambiar de destino sin ascender.

También puede ascender sin cambiar de destino.

Ejemplos:

```text
Alférez → Teniente júnior
Destino: permanece igual
```

o:

```text
Rango: Teniente
Destino A → Destino B
Rango: permanece igual
```

## Campaña

Los destinos disponibles dependen de:
- fecha,
- necesidades de Starfleet,
- vacantes,
- especialidad,
- reputación,
- expediente,
- relaciones,
- consecuencias de campaña.
