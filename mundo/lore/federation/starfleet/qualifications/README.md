# Cualificaciones de mando

## Principio

**Rango y cualificación de mando son datos diferentes.**

Un oficial puede poseer un rango elevado y no estar cualificado para asumir determinadas funciones de mando de puente.

Del mismo modo, un oficial joven puede estar autorizado a dirigir una guardia si posee la formación y designación adecuadas.

## Cualificación genérica del proyecto

CoreRPG usará:

```text
command_qualified = true | false
```

y podrá añadir niveles o habilitaciones concretas en el futuro.

## Pike / Kirk

El proyecto no afirma que existiera exactamente el mismo examen visto en TNG.

La cualificación de mando se obtendrá mediante:
- formación,
- experiencia,
- evaluaciones,
- servicio de puente,
- autorización de superiores,
- cursos/escuela de mando cuando corresponda a la época.

## TNG + DS9 + Voyager

En el siglo XXIV está documentado el **Bridge Officer's Test** para oficiales que desean estar cualificados para asumir mando desde otras ramas.

El examen incluye materias como:
- diplomacia,
- funciones de mando,
- ingeniería,
- táctica,
- toma de decisiones bajo presión.

La prueba final puede exigir demostrar que el candidato es capaz de tomar decisiones extremadamente duras para salvar la nave y la tripulación.

## Regla de jugabilidad

El juego no regalará mando solo por ascender de rango.

Para ciertos puestos o guardias será necesario:
- rango mínimo cuando proceda,
- cualificación de mando,
- experiencia,
- evaluación satisfactoria,
- designación o destino compatible.

Esto permite una carrera orgánica hacia Primer Oficial y Capitán.
