# Reglamentos de la Flota Estelar

## Enfoque del proyecto

Star Trek menciona numerosas órdenes, reglamentos, directivas, códigos y protocolos.

No se copiará una lista indiscriminada de números sin contexto.

Cada norma se incorporará cuando:
- esté respaldada por una fuente,
- tenga efecto real sobre personajes o simulación,
- sea relevante para las eras jugables.

## Primera capa implementada

- Primera Directiva / General Order 1
- autoridad médica para declarar no apto para el servicio
- cualificación de mando
- Directiva Omega como conocimiento clasificado en el siglo XXIV

## Regla de runtime

Las normas pueden:
- permitir,
- prohibir,
- exigir,
- recomendar,
- conceder autoridad,
- imponer consecuencias.

Pero una prohibición normativa no debe confundirse con una imposibilidad física.

Esto permite que el jugador pueda desobedecer y que el mundo reaccione.
