# Ascensos

## Principio

Un ascenso es el paso a un rango superior.

El juego **no usa una equivalencia directa entre XP y rango**.

## Factores

Un ascenso puede depender de:
- historial de servicio,
- desempeño,
- evaluaciones,
- cualificaciones,
- experiencia,
- recomendaciones,
- necesidades de personal,
- disponibilidad de puestos,
- autoridad competente,
- conducta disciplinaria.

El tiempo de servicio por sí solo no garantiza un ascenso.

## Puesto y rango

Ascender no implica automáticamente recibir un nuevo mando.

Ejemplos:
- un Comandante puede seguir siendo Primer Oficial,
- un Capitán puede ocupar un puesto de estado mayor,
- un oficial puede recibir un nuevo puesto antes o después de un ascenso.

## Ceremonia

Cuando proceda, la promoción puede mostrarse como un acontecimiento narrativo:
- orden oficial,
- cambio de insignia,
- felicitación del superior,
- actualización de expediente.

## Gameplay

CoreRPG podrá acumular experiencia y méritos internamente, pero el ascenso debe producirse mediante una decisión del mundo:

```text
eligible_for_promotion = true
        +
promotion_authority_decision
        +
campaign circumstances
        ↓
promotion
```

No se asciende automáticamente al llenar una barra.
