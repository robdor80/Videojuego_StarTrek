# Perfil de Academia — Kirk / TOS + películas

## Subperiodos

La era Kirk contiene cambios grandes y se divide visual/operativamente en:

### TOS — 2265–2269
- estética TOS;
- entrenamiento físico y técnico;
- simuladores no holográficos;
- cadete como término principal de juego.

### Películas — finales de 2270s–2293
- uniformes y presentación de la etapa cinematográfica;
- `midshipman / guardiamarina` puede aparecer como término de época;
- Starfleet Training Command;
- simuladores de puente;
- cruceros de instrucción;
- naves reales usadas como plataformas docentes.

## Kobayashi Maru

En 2285, el escenario Kobayashi Maru está disponible como contenido canónico para formación de mando.

No se fuerza:
- fuera de fechas compatibles;
- a todas las especializaciones;
- como misión que el jugador deba "ganar".

## Pips

Los cadetes siguen usando los pips plateados universales del proyecto para legibilidad aunque el uniforme histórico use otros distintivos.
