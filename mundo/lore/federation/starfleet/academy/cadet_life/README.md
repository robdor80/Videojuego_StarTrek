# Vida de cadete — base jugable

## Duración

La formación estándar de oficial se modela como un programa de cuatro años.

En el siglo XXIV, los rangos/clases de cadete se corresponden con:

| Año | Clase de cadete |
|---:|---|
| 1.º | Cadete de 4.ª clase |
| 2.º | Cadete de 3.ª clase |
| 3.º | Cadete de 2.ª clase |
| 4.º | Cadete de 1.ª clase |

Tras graduarse, el destino normal del cadete es recibir comisión como **Alférez**.

## Pike / Kirk

Las denominaciones históricas pueden variar y el término `midshipman` / guardiamarina aparece en el siglo XXIII.

Para jugabilidad, el proyecto mantiene internamente una progresión de cuatro años común y permite que la presentación de era use la terminología apropiada.

## Vida cotidiana

La Academia no es solo clases.

La campaña de cadete puede contener:
- alojamiento,
- formación,
- clases,
- estudio,
- simulaciones,
- entrenamiento físico,
- vuelo,
- clubes/equipos,
- amistades,
- rivalidades,
- tutorías,
- disciplina,
- permisos y tiempo libre.

## Conducta

El expediente académico incluye conducta.

El caso de Nova Squadron demuestra que:
- un error de entrenamiento puede causar consecuencias graves,
- un encubrimiento puede empeorar el resultado,
- puede haber expulsión,
- otros cadetes pueden ser obligados a repetir un año.

## Regla de juego

La progresión anual no depende únicamente de aprobar asignaturas.

También puede depender de:
- evaluaciones,
- conducta,
- requisitos prácticos,
- cualificaciones,
- formación de campo.

## No linealidad

Repetir un año, suspender un módulo o recibir una sanción no termina necesariamente la campaña.

La vida académica debe poder desviarse y recuperarse.
