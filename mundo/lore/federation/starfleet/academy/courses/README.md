# Asignaturas y módulos

## Regla

El catálogo jugable no pretende afirmar que todas las asignaturas se impartieran exactamente igual en todas las eras.

Cada curso indica:
- nombre en castellano,
- competencias,
- tipo,
- eras,
- procedencia.

## Tronco común jugable

El juego sintetiza como módulos comunes:
- Reglamentos y ética de Starfleet
- Protocolo interespecies
- Fundamentos de liderazgo
- Supervivencia
- Preparación física
- Respuesta a emergencias

Algunos son síntesis `GAME_ADDITION` de contenidos canónicos dispersos.

## Materias canónicas/referenciadas utilizadas

Entre las materias documentadas o referenciadas en Star Trek y útiles para nuestro juego están:
- Mando y control
- Navegación avanzada
- Control de vuelo
- Diplomacia
- Ingeniería
- Diseño warp básico
- Teoría warp
- Teoría de transportadores
- Análisis táctico
- Estrategia y táctica
- Combate cuerpo a cuerpo
- Astrofísica
- Cartografía estelar
- Exobiología
- Xenolingüística
- Mecánica temporal
- Estrategias de supervivencia

## Filosofía de resolución

Una asignatura no es un cuestionario al usuario.

Cada curso genera:
- escenas de clase,
- prácticas,
- trabajos,
- tutorías,
- simulaciones,
- evaluaciones.

El conocimiento del personaje determina qué opciones entiende y ejecuta; el jugador toma las decisiones.
