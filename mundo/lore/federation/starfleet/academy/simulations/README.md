# Simulaciones

## Función

Las simulaciones permiten entrenar situaciones demasiado costosas, peligrosas o raras para reproducirlas de forma real.

Pueden evaluar:
- mando;
- navegación;
- ingeniería;
- táctica;
- seguridad;
- medicina;
- ciencia;
- cooperación;
- crisis.

## Tecnología por era

### Pike / Kirk

La era puede usar simuladores físicos, maquetas de puente y sistemas específicos de entrenamiento.

### Kirk — películas

En 2285 se ve un simulador de puente usado con cadetes y el escenario Kobayashi Maru.

### TNG + DS9 + Voyager

La tecnología holográfica permite escenarios mucho más flexibles.

## Kobayashi Maru

El Kobayashi Maru está documentado como una prueba de escenario sin victoria para cadetes orientados a mando en el siglo XXIII.

### Regla del juego

No convertirlo en una "misión que hay que ganar".

El sistema evalúa:
- comportamiento;
- disciplina;
- decisiones;
- liderazgo;
- reacción ante pérdidas inevitables.

No se importará automáticamente como prueba obligatoria idéntica en todas las eras si la evidencia no lo respalda.

## Simulaciones emergentes

El juego puede generar escenarios nuevos a partir de plantillas:
- fallo warp;
- primer contacto;
- evacuación;
- motín;
- heridos masivos;
- intrusión;
- anomalía;
- combate;
- dilema de mando.

Las condiciones y solución deben ser autoritativas; la IA presenta y dramatiza.
