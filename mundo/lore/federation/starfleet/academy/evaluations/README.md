# Evaluaciones

## Qué se evalúa

La Academia no mide solo memoria académica.

Según curso/actividad pueden evaluarse:
- conocimiento;
- ejecución práctica;
- juicio;
- liderazgo;
- trabajo en equipo;
- comunicación;
- integridad;
- preparación;
- disciplina;
- control bajo presión.

## Notas del juego

El sistema usa una puntuación interna cuando hace falta, pero al jugador se le muestran categorías comprensibles:

- **Excelente**
- **Notable**
- **Apto**
- **En recuperación**
- **No apto**

No se pretende afirmar que ésta fuera la escala literal usada por Starfleet en pantalla. Es una normalización de juego.

## Fracaso

Un mal resultado académico suele producir contenido antes que cierre de campaña:
- recuperación;
- tutoría;
- repetición;
- práctica adicional;
- pérdida de oportunidad;
- retraso.

La falta de integridad o una infracción grave puede tener consecuencias disciplinarias independientes de la nota.

## Expediente

Cada evaluación importante queda registrada con:
- actividad;
- fecha;
- instructor;
- criterios;
- resultado;
- comentarios;
- consecuencias.
