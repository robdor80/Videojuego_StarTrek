# Tellaritas — gameplay

The main gameplay hook is social interpretation, not a generic physical bonus.

Retained rules:
- argument and debate can be positively valued;
- complaints or insults may function as conventional engagement;
- sharp speech is not automatically hostility;
- individual Tellarites may follow these norms strongly, weakly or not at all.

Diplomacy and AI tone classification must use cultural familiarity and context.
