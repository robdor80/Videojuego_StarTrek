# Alianza Ferengi — gameplay

Retain only what changes play:
- contracts, commercial law, exchange and regulatory authority can create real consequences;
- the Grand Nagus and commercial institutions matter when authority is relevant;
- profit culture can shape negotiation without turning every Ferengi into the same personality;
- Ferengi social rules can change during the campaign and across dates.

Never infer trader profession, citizenship or morality from species.
