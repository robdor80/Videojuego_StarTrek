# Equipo de dotación personal

Índice cruzado del [catálogo único](../lore02_b_equipment_catalogue_v0.1.json): comunicadores, PADD, EVA, protección y equipo asignado. La [matriz de dotaciones](../lore02_b_roles_loadouts_v0.1.json) son plantillas condicionales, no inventario gratuito.

Un `equipment_id` define una familia de referencia; un `object_id` designará, en runtime futuro, una instancia persistente con propietario, localización, integridad, consumibles y registro de transferencias.
