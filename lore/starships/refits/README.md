# Refit de naves

Los refits se modelan como cambios persistentes sobre una nave individual.

## Separación

```text
CLASE
≠
CONFIGURACIÓN DE ÉPOCA
≠
PAQUETE DE REFIT
≠
NAVE INDIVIDUAL
```

Un refit histórico de una nave concreta no convierte automáticamente esa configuración en estándar para toda su clase.

## Gameplay

Un refit puede requerir:
- dique compatible;
- astillero;
- piezas;
- especialistas;
- tiempo;
- retirada temporal del servicio;
- pruebas de muelle;
- pruebas de espacio.

No existe una tienda universal de mejoras instantáneas.

## Campaña

Los refits canónicos anteriores al inicio de campaña pueden formar parte del bootstrap histórico.

Después del inicio:
- el World State manda;
- la nave puede o no recibir un refit;
- el trabajo puede retrasarse, bloquearse o cancelarse;
- la configuración resultante pasa a la historia propia de esa partida.
