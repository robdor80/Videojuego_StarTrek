# Clasificaciones de naves

Una clasificación describe función/rol general y **no es sinónimo de clase**.

## Categorías jugables iniciales

El proyecto usará categorías amplias y reutilizables:

- Exploración
- Ciencia / investigación
- Crucero
- Escolta
- Patrulla
- Transporte
- Carga
- Apoyo
- Médico
- Entrenamiento
- Lanzadera / nave auxiliar

Una clase puede tener más de un rol razonable según:
- época;
- configuración;
- misión;
- refit.

## Regla

No forzar una taxonomía militar moderna sobre Starfleet cuando la fuente no lo haga.

La clasificación sirve principalmente para:
- selección de misiones;
- generación de destinos;
- IA de planificación;
- filtros de interfaz;
- disponibilidad de puestos;
- expectativas de capacidad.
