# Starfleet Uniforms — Project Rules

## Two layers

The project separates:

1. **historical uniform appearance and division colors**
2. **project-standard rank pips**

The first stays era-accurate. The second is intentionally unified across eras.

## Pike / Strange New Worlds

Primary visual division language:
- Command — gold
- Operations / Security — red
- Sciences — blue
- Medical — medical variants based around light blue / white

Historical rank stripes/insignia are visually replaced or supplemented by the universal game pip standard.

## Kirk / TOS

Primary TOS division language:
- Command — gold / greenish-gold
- Operations / Engineering / Security — red
- Sciences / Medical — blue

Again, rank recognition uses the universal project pips.

## Kirk film period

The films materially change the uniform system.

### Mid-2270s / TMP style

Department is carried by smaller colored identifiers rather than a full division-colored shirt:
- Command — white
- Sciences — orange
- Medical — light green
- Engineering — red
- Operations — pale gold
- Security — silver

### 2280s–2293 maroon style

The main jacket is maroon. Department is indicated by collar/undershirt/trim:
- Command — white
- Operations — yellow ochre
- Medical — light green
- Sciences — grey
- Security — Windsor green
- Cadets / trainees — flame red
- Special services — sky blue
- Enlisted / NCO — black

The project keeps those period colors, while rank itself remains readable via the universal pip overlay/insignia.

## TNG + DS9 + Voyager

Primary division language:
- Command — red
- Operations / Engineering / Security — gold
- Sciences / Medical — blue/teal

The official Star Trek reference explicitly identifies TNG command as red, support/operations as gold, and sciences as blue.

## Principle

**Era tells you what the uniform looks like. Pips tell you the rank.**
