# Puestos de servicio (Duty Stations)

Un **puesto de servicio** es el lugar físico u operativo donde una persona presta servicio durante un turno o situación.

Ejemplos:
- silla de mando
- Conn / control de vuelo
- Ops
- Táctica
- estación científica
- Ingeniería principal
- Enfermería
- Transportadores

No debe confundirse con `Assignment / Destino`.

Una persona puede estar destinada en una nave durante años y ocupar distintos puestos de servicio según turno, alerta, emergencia o sustitución.
