# Primer destino

## Principio

El primer destino es una decisión del mundo, no una recompensa prefijada.

Se calcula a partir de:
- fecha;
- unidades disponibles;
- vacantes;
- especialización;
- cualificaciones;
- expediente;
- conducta;
- preferencias del cadete;
- necesidades de Starfleet;
- estado de campaña.

## Preferencias del jugador

Antes de graduarse, el jugador puede expresar preferencias:
- nave;
- estación;
- exploración;
- ciencia;
- frontera;
- ingeniería;
- seguridad;
- sector concreto;
- tipo de misión.

Las preferencias influyen, pero no garantizan resultado.

## Unidades famosas

El jugador puede llegar a una unidad famosa si existe una vacante compatible.

No existe una regla oculta de "protagonista → Enterprise".

## Resultado

El primer destino genera:
- nueva `Assignment`;
- nuevo puesto;
- supervisor/cadena de mando;
- fecha de incorporación;
- transición de cadete a oficial.

## Persistencia

El expediente completo de la Academia viaja con el personaje y puede influir en:
- percepción de superiores;
- oportunidades;
- mentores;
- ascensos futuros;
- destinos posteriores.
