# Campus — base de referencia para jugabilidad

## Alcance retenido

Para las tres eras jugables, la Academia terrestre se sitúa en el área de San Francisco / Golden Gate, con instalaciones vinculadas al Presidio y a terrenos al norte del puente en Marin County.

Las referencias conservadas permiten usar como elementos de base:
- campus/terrenos de la Academia,
- patio de instrucción,
- Escuela de Mando,
- Escuela de Vuelo,
- Escuela Táctica,
- Academia Médica de la Flota Estelar.

## Regla de adaptación

Estos elementos no forman una lista suficiente para un videojuego.

Por ello el gameplay añade espacios funcionales como:
- alojamiento,
- comedor,
- centro de estudio,
- complejo de simulación,
- núcleo académico.

Esos espacios se registran como `GAME_ADDITION` y existen para hacer jugable la institución.

## Fuente visual/geográfica

El Golden Gate y los terrenos de San Francisco/Marin son una parte importante de la identidad visual del campus en las eras retenidas.

## No usar como canon de nuestras eras

La serie del siglo XXXII `Star Trek: Starfleet Academy` queda fuera del alcance jugable establecido y no se usa para importar instalaciones, personajes o tecnología propios de esa época.
