# Exámenes

## Formatos

Starfleet muestra o referencia distintos formatos:
- escritos;
- orales;
- prácticos;
- simulaciones;
- evaluaciones psicológicas;
- evaluación de campo.

## Regla jugable

El formato cambia la escena, no obliga al usuario a contestar trivia.

### Escrito/oral
El personaje aporta conocimiento y preparación; el jugador decide enfoque y respuestas de alto nivel.

### Práctico
Se resuelve mediante acciones, decisiones, reglas y estado.

### Simulación
Se usa un escenario completo con objetivos visibles y ocultos.

### Psicológico
Evalúa reacción y carácter; no busca una "respuesta correcta" única.

## Integridad

Copiar, falsificar un informe, manipular una simulación o encubrir un accidente son acciones posibles si la situación lo permite.

No están bloqueadas físicamente: generan riesgos y consecuencias.
