# Divisiones y especializaciones de la Academia

## Regla de juego

La Academia prepara al cadete para una carrera dentro de Starfleet, pero la especialización inicial **no es una prisión profesional**.

El personaje puede:
- empezar indeciso,
- declarar una división,
- elegir una especialización,
- cambiar de especialización con coste académico,
- añadir formación secundaria,
- reconvertirse más adelante mediante cursos y experiencia.

## Divisiones base

### Mando

Orientada a:
- liderazgo,
- toma de decisiones,
- coordinación de tripulación,
- navegación/control de vuelo,
- operaciones de puente,
- diplomacia y mando.

Especializaciones jugables iniciales:
- **Mando**
- **Control de vuelo y navegación**

### Operaciones

Orientada a:
- sistemas de nave,
- ingeniería,
- mantenimiento,
- operaciones,
- seguridad,
- táctica.

Especializaciones jugables iniciales:
- **Ingeniería**
- **Operaciones**
- **Seguridad y Táctica**

### Ciencias

Orientada a:
- investigación,
- análisis,
- ciencias físicas,
- ciencias biológicas,
- cartografía,
- exociencias.

Especializaciones jugables iniciales:
- **Ciencias**
- **Astrofísica y cartografía**
- **Exociencias**

### Medicina

La medicina se trata como una **ruta profesional especializada** vinculada a Starfleet Medical / Starfleet Medical Academy.

Para el juego aparece integrada en la experiencia Academy, pero se marca aparte para no fingir que un médico sigue exactamente el mismo plan que un cadete generalista.

## Canon y normalización

Star Trek muestra muchas carreras y títulos académicos concretos: ingeniería, astrofísica, exobiología, xenolingüística, probabilidad, etc.

El juego no obligará al usuario a escoger entre decenas de carreras minúsculas desde el primer día.

En cambio:

```text
DIVISIÓN
   ↓
ESPECIALIZACIÓN JUGABLE
   ↓
ASIGNATURAS / OPTATIVAS / CUALIFICACIONES
```

Así podemos mantener riqueza sin convertir la creación del personaje en una hoja universitaria interminable.
