# Destinos (Assignments)

Un **destino** es la organización, nave, estación, instalación o unidad a la que una persona está destinada.

Ejemplos:
- USS Enterprise-D
- USS Voyager
- Deep Space 9
- Academia de la Flota Estelar
- una base estelar
- una oficina de Starfleet Command

El destino no es el puesto.

Ejemplo:

```text
Rango: Teniente comandante
Puesto: Jefe de Ingeniería
Destino: USS Example
```
