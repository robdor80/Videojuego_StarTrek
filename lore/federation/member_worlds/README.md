# Mundos miembros de la Federación

## Principio

La afiliación política se modela por **mundo/gobierno**, no por especie.

Un personaje vulcano puede pertenecer a Starfleet, a una administración vulcana, a una organización privada o actuar individualmente. Su especie no determina automáticamente su autoridad política.

## Núcleo fundador

El proyecto retiene cuatro miembros fundadores en 2161:

| ID interno | Mundo / entidad de origen | Especie asociada principal |
|---|---|---|
| `earth` | Tierra / Tierra Unida | Humanos |
| `vulcan` | Vulcano | Vulcanos |
| `andoria` | Andoria | Andorianos / Aenar |
| `tellar_prime` | Tellar Prime | Tellaritas |

La denominación política histórica exacta de cada miembro puede cambiar con la fecha; el runtime debe separar el **mundo** de la **entidad gubernamental activa**.

## Gameplay

La pertenencia a la Federación puede afectar:
- jurisdicción;
- acceso diplomático;
- permisos de tránsito;
- respuesta de Starfleet;
- tratados aplicables;
- derechos y obligaciones reconocidos;
- disponibilidad de destinos y misiones;
- conocimiento inicial de culturas y sistemas.

No concede conocimiento omnisciente ni amistad automática entre personajes.

## Expansión progresiva

El catálogo completo de mundos miembros no se bloqueará intentando enumerar todos los miembros de una sola vez. Se incorporan mundos cuando:
1. sean necesarios para una era jugable;
2. aparezcan en una misión, personaje o ruta;
3. afecten a diplomacia, fronteras o historia;
4. exista suficiente procedencia para modelarlos.
