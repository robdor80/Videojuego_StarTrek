# Imperio Estelar Romulano — gameplay

Retain only what changes play:
- Neutral Zone status can create immediate navigation/jurisdiction consequences;
- cloaked contacts require sensor/knowledge resolution rather than omniscient identification;
- intelligence and covert-action risk can be elevated without making every Romulan a spy;
- Federation relation state changes with date and campaign history.

Never infer Tal Shiar membership from species.
