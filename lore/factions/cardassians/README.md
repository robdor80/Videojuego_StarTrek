# Unión Cardassiana — gameplay

Retain only what changes play:
- Cardassian state authority, border policy and military/intelligence institutions can affect inspections, detention, negotiation and conflict;
- the Bajoran occupation is historical state that changes trust, memories and jurisdictional context;
- alignment with the Dominion is date-dependent and must not be backfilled before it happens;
- individual Cardassians can oppose, serve or ignore state policy.

Never infer Union loyalty from Cardassian species.
