# Colectivo Borg — gameplay

Retain only what changes play:
- ordinary diplomacy is not the default interaction model;
- assimilation is a live threat state;
- Borg adaptation, boarding and collective coordination must be Core-owned mechanics;
- temporary tactical cooperation can exist without creating normal diplomatic relations;
- liberated/disconnected Borg are individual character states, not ordinary drones.

The AI cannot decide that assimilation succeeded, adaptation occurred or a drone regained individuality.
