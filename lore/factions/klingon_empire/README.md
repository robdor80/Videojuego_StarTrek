# Imperio Klingon — gameplay

Retain only what changes play:
- central policy comes from Imperial leadership, but Great Houses and local commanders can pursue different interests;
- Federation relation state changes sharply by date, so no permanent "enemy" or "ally" flag is allowed;
- honor language and challenge customs affect interpretation, negotiation and escalation, but never define every Klingon;
- border entry, military posture and rules of engagement come from live relation state.

Never infer Imperial loyalty from Klingon species alone.
