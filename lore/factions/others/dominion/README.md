# Dominio — gameplay

Retain only what changes play:
- Founders, Vorta and Jem'Hadar form distinct authority/operational layers;
- diplomacy, infiltration, coercion and military pressure can coexist;
- non-aggression pacts and subordinate-state relationships are temporal state;
- Cardassian membership is date-dependent;
- hidden Changeling identity is knowledge-gated.

The AI cannot reveal infiltrators or hidden intent unless Core knowledge state permits it.
