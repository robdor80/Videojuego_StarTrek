# Factions

Faction content exists to drive jurisdiction, diplomacy, borders, mission authority, conflict, trade, security and campaign consequences.

The repository does not maintain faction pages as encyclopedic summaries. A retained fact belongs here only when it can affect:
- who has authority;
- what territory or installation is controlled;
- which laws/treaties apply;
- whether travel, trade or military access is permitted;
- how a contact is identified;
- what a representative can negotiate;
- current war/peace/alliance state;
- what changes in persistent World State.

Hard rule:

FACTION != SPECIES != CULTURE != CHARACTER

Political state is temporal. Canon initializes history up to campaign start; live campaign state owns the future.
