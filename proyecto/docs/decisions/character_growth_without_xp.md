# Character Growth Without XP — decisión de diseño

Status: **LOCKED BASELINE**

## Regla principal

> **El personaje no mejora porque recibe puntos. Mejora porque vive, estudia, entrena, trabaja y repite actividades durante el tiempo suficiente.**

No existe reparto manual de puntos, nivel global ni barra genérica de XP para el jugador.

El motor sí puede mantener medidas internas para resolver situaciones y representar diferencias finas entre personajes. Esas medidas:
- no se reparten manualmente;
- no son la interfaz de progreso;
- cambian únicamente por evidencia del mundo;
- se traducen al jugador mediante descripciones, experiencia, certificaciones y resultados observables.

## Fuentes de evolución

Una capacidad puede cambiar por:
- estudio;
- instrucción;
- observación;
- práctica deliberada;
- simulación;
- trabajo supervisado;
- uso operativo real;
- repetición sostenida;
- enseñanza a otros;
- experiencias extraordinarias;
- descanso, lesión, desentrenamiento o recuperación.

## Transferencia

Experiencia relacionada puede facilitar aprendizaje nuevo sin convertir automáticamente una competencia en otra.

Ejemplo:

```text
karate avanzado
→ transfiere equilibrio, distancia, timing y disciplina
→ facilita aprender Mok'bara
→ NO convierte al personaje en experto en Mok'bara
```

## Deterioro

La inactividad afecta primero a recencia, condición y ejecución específica. La experiencia profunda y el conocimiento no desaparecen de inmediato.

Recuperar una capacidad previamente desarrollada puede ser más rápido que aprenderla desde cero.

## Aplicación universal

El mismo principio sirve para:
- deporte;
- artes marciales;
- música;
- idiomas;
- ciencia;
- medicina;
- ingeniería;
- navegación;
- sensores;
- liderazgo;
- hobbies;
- oficios;
- cualquier competencia futura válida.

No se programará una excepción individual por hobby si puede modelarse como actividad + evidencia + capacidad.
