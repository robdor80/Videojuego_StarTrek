# Academy Access v1.0 — decisión de diseño

Status: **LOCKED BASELINE**

El acceso existe como prólogo jugable serio, pero no puede convertirse en un curso previo a la Academia.

> **ACCESO = qué es Starfleet y qué clase de institución intenta integrar el candidato.**  
> **ACADEMIA = cómo funciona, cómo se opera y cómo se ejerce profesionalmente.**

## Temario oficial

1. **ACC-01 — Federación y Flota Estelar**
2. **ACC-02 — Cómo se organiza Starfleet**
3. **ACC-03 — Vida a bordo de una nave**
4. **ACC-04 — Tecnología básica de Starfleet**
5. **ACC-05 — Principios del servicio en Starfleet**

No se añaden astrográfica, navegación, sensores, ingeniería, medicina, tácticas, protocolo profesional detallado, ecuaciones warp, historia memorística, clases de nave o reglamentos avanzados. Eso pertenece a la Academia.

## Evaluación

La admisión es holística: conocimientos generales limitados al temario, razonamiento, interacción, evaluación psicológica, prueba práctica general, entrevista y revisión final.

No existe una regla player-facing del tipo «79 % fuera / 80 % dentro». Equivocarse en varias preguntas no implica rechazo automático.

## Reintentos

Un fallo no reinicia toda la candidatura por defecto. La Academia conserva evidencia válida y puede prescribir preparación adicional, repetición parcial, programa preparatorio o nuevo intento posterior.

El historial de intentos persiste como biografía.

## Eras

La arquitectura es común a Pike, Kirk y TNG/DS9/Voyager. La tecnología, presentación y grado de detalle canónico se adaptan a la era.

## Web / PDF / juego

Los mismos IDs y el mismo temario alimentan videojuego, manual/PDF, web externa, prácticas y evaluación. No existe un canon académico paralelo.
