### Reproducción

Usar un checkout limpio de CoreRPG en el pin y redirigir temporales y salidas al laboratorio de la tarea. En Windows, añadir `-A x64` en las dos configuraciones. La [matriz HOST](../../../../.github/workflows/host-h02-native.yml) incluye los flags ASan/UBSan, los targets de regresión y F11 aislado.

```powershell
cmake -S desarrollo/integration/host -B "$build" "-DCORERPG_SOURCE_DIR=$core" -DTREK_HOST_TESTS=ON -DCMAKE_BUILD_TYPE=Release
cmake --build "$build" --config Release --parallel 3 --target host_biography_tests host_abi_tests
ctest --test-dir "$build" -C Release -R '^(host[.]biography[.]|host[.]abi[.]unsupported_academy_open$)' --no-tests=error --output-on-failure
cmake -S desarrollo/integration/host -B "$product" "-DCORERPG_SOURCE_DIR=$core" -DTREK_HOST_TESTS=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build "$product" --config Release --parallel 3 --target TrekHost
python desarrollo/integration/host/tests/inspect_product.py "$product"
python desarrollo/integration/host/tests/inspect_abi.py "$product"
python -m unittest discover -s desarrollo/tools/validation -p 'test_f10_*.py' -v
```
