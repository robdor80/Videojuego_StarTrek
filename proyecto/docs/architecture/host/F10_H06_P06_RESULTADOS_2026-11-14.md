## Reproducción

Usar un checkout limpio de CoreRPG en el pin y un directorio nuevo de build en la zona temporal ignorada indicada por AGENTS.md. Redirigir `TEMP`, `TMP`, `TMPDIR` y `F04_TEST_TEMP_ROOT` a esa zona. En Windows seleccionar un generador Visual Studio con `-A x64`; en Linux omitir esa opción y usar `-DCMAKE_BUILD_TYPE=Release`.

```powershell
cmake -S desarrollo/integration/host -B "$build" -A x64 "-DCORERPG_SOURCE_DIR=$core" -DTREK_HOST_TESTS=ON
cmake --build "$build" --config Release --target host_academy_feasibility_tests host_abi_tests
ctest --test-dir "$build" -C Release -R '^(host[.]academy[.]core_feasibility|host[.]abi[.]unsupported_academy_open)$' --no-tests=error --output-on-failure
```

El [workflow HOST](../../../../.github/workflows/host-h02-native.yml) conserva la selección CTest, los targets, flags de sanitizadores, comandos Release OFF y recolección de JUnit.
