# NCC-1700 / Franz Joseph reference blueprints

Reference set for the **Constitution class** based on the Franz Joseph `Booklet of General Plans` material centered on **USS Constitution NCC-1700**.

## Project use

This set is stored at class level because it is intended to inform the baseline spatial model for Constitution-class ships in the TOS/Kirk period. It must not be treated as an Enterprise-A-specific interior layout.

Potential uses include:
- deck and compartment indexing;
- location graphs and turbolift connectivity;
- placement of major ship systems;
- class-level interior baselines;
- later per-ship and per-era overrides.

## Provenance boundary

These files are **reference material, not SCREEN_CANON**. Any factual claim promoted from the blueprints into structured lore or gameplay data must receive normal project provenance and confidence metadata. Conflicts with retained screen canon are resolved in favor of retained screen canon.
