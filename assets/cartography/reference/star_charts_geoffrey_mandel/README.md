# Star Trek: Star Charts — reference atlas

This directory stores the project copy of **Star Trek: Star Charts** by Geoffrey Mandel (2002).

## Project role

The atlas is used as an **OFFICIAL_REFERENCE** for:
- quadrant and sector reference structure;
- local-space placements;
- political maps by period;
- route and trade-map context;
- Bajor/Cardassia geography;
- Klingon and Romulan reference maps;
- Dominion War cartography;
- Gamma/Delta Quadrant reference;
- Voyager route context.

It is not SCREEN_CANON. Screen evidence overrides conflicting atlas placements.

## Gameplay extraction rule

Do not copy the book into lore prose.

Extract only data that affects:
- navigation;
- route planning;
- jurisdiction;
- political borders;
- exploration knowledge;
- strategic locations;
- travel uncertainty.

Derived data must keep provenance and confidence.
