# STAR TREK — EQUIPMENT / PROP VISUAL BIBLE v0.1

**Status:** FOUNDATION APPROVED FOR PROCEDURAL TESTING
**Inherits:** STAR_TREK_GLOBAL_VISUAL_BIBLE_v0.1

## Principle

Every prop is an object with maker/operator, era, function and state.

Resolve:

`era → civilization/operator → equipment type/model → individual instance if persistent → current condition → use context`

## Functional readability

A tricorder, medical tool, engineering tool, weapon, communicator or container should communicate its function through approved design language.

Do not add:
- arbitrary glowing panels;
- random buttons;
- modern consumer-device cues;
- unsupported attachments.

## Model vs instance

Mass-produced equipment can use a model definition.

A unique/persistent instance receives:
- object_id;
- visual identity where needed;
- ownership/location;
- modifications;
- damage/repair history.

## State

Wear, damage, contamination and missing components require real use/events.

A clean issued tool may be visually maintained; “used future equipment” does not imply grime.

## Era

Equipment family must be valid for the campaign date/platform/organization.
Cross-era props require explicit historical or special context.
